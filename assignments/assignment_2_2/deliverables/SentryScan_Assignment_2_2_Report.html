1. Executive Summary & Theoretical Context

Assignment 2.2 transitions SentryScan into a distributed multi-agent architecture communicating over structured network sockets using formal speech-act performatives (Wooldridge, MultiAgent Systems).

1.1 Speech Act Theory & Agent Communication Languages (ACL)

Agents do not communicate via raw passive remote procedure calls. They exchange communicative speech acts with intentional semantics: - Performatives: ALERT (informing critical findings), PARAMS_UPDATE (commanding operational parameter shifts), TASK_REQUEST, CFP, PROPOSE, and ERROR. - Closed Envelope Model: Standardized message schema containing message_id, sender, recipient, performative, conversation_id, reply_to, timestamp, and structured payload.

1.2 Binary Stream Framing & Fault Resilience

TCP is an un-delimited byte stream. To guarantee reliable deserialization over network sockets: - Length-Prefixed Framing: Messages are prefixed with a 4-byte big-endian unsigned integer (!I), denoting exact payload byte count. - Partial Chunk Accumulation: FrameReader buffers chunked socket streams and handles packet fragmentation seamlessly. - Fault Isolation: Corrupted frames or non-JSON payloads are safely rejected at the transport boundary with an ERROR response, preventing agent daemon crashes.
