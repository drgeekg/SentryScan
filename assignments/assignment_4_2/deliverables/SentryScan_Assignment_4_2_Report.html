1. Executive Summary & Theoretical Context

Assignment 4.2 integrates formal Knowledge Representation & External API Enrichment (Russell & Norvig, Ch. 12) into SentryScan, allowing the agent to augment sparse perceptual banners with authoritative external cybersecurity knowledge.

1.1 Ontology-Driven Epistemic Grounding

Raw telemetry provides only ambiguous version strings (e.g., ProFTPD 1.3.5, log4j 2.14.1). Grounding this percept in a formal Vulnerability Knowledge Ontology maps the surface observation to: - Canonical CVE Identifiers (CVE-2021-44228, CVE-2024-3094). - Common Weakness Enumeration (CWE) taxonomies (CWE-502 Deserialization, CWE-78 OS Command Injection). - Mathematical CVSS v3.1 Base Scores and authoritative mitigation strategies.

1.2 Multi-Tiered Enrichment & Resilient Fallbacks

Network endpoints fail, rates throttle, and air-gapped environments forbid external calls. SentryScan implements a 4-tier resilient knowledge pipeline: 1. In-Memory / SQLite Persistent Cache: Fast sub-millisecond retrieval with TTL invalidation. 2. NVD REST API Adapter: Read-only client querying NIST's National Vulnerability Database with bounded exponential backoff retries. 3. Local Knowledge Ontology: Curated JSON ontology fixture for known high-impact exploit signatures. 4. Deterministic Fallback Fixture: Guarantees 100% operational uptime without agent crash during complete network outages.
